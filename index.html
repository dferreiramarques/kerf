What it does

Everything between "raw sample" and "playable instrument."

No plugins, no install required to start — Kerf runs on the Web Audio API and keeps every project local to your machine.

01

Import & record

Load any audio file or record straight from your microphone — no conversion step.

02

Transient detection

Auto-detect slice points with adjustable sensitivity, then fine-tune every boundary by hand.

03

Live parameter control

Adjust in/out points, pitch, volume and pan in real time, with instant retrigger as you turn the knob.

04

16-step sequencer

Build patterns across 8 scenes and arrange your slices into a full performance.

05

Dual MIDI modes

Trigger mode fires a different slice per note. Sampler mode plays one slice across a piano layout.

06

Project save/load

Slices, patterns and settings export as a single ZIP — hand it off or pick it back up later.

Two ways to play

Built for kits and for pitched playing alike.

Mode 01

Trigger

Every MIDI note or key fires a different slice. The virtual keyboard shows only the slices you've configured — built for playing multi-sample kits.

Mode 02

Sampler

One slice, played across a piano layout — A maps to middle C, higher notes pitch up from there. External MIDI only, for pitch-accurate playing.

Signal path

A four-stage effects chain on every slice.

Reverb, compression, overdrive and bit-crushing — chained in order, dialed in per project.

Reverb

Wet/dry mix, off by default.

Compressor

Attack, release and ratio control.

Overdrive

Drive and tone shaping.

Decimator

Bit depth and sample-rate reduction.
