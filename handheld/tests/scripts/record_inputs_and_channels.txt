# The Record screen with the pretend inputs: a receiver that sends nothing, a mixer with twelve
# channels (a pair of them is recorded, with gain) and an input that cannot be opened.
# Run from the repository root, with a folder that is empty (the takes are saved there):
#   kerf_headless --script handheld/tests/scripts/record_inputs_and_channels.txt --fake-input --start-dir <empty folder>
# The inputs that Kerf reads itself are listed first: microphone, silent receiver, mixer, broken input.

frames 30
expect screen record
expect inputs 4
expect input Pretend USB microphone
expect channels 1+2

# ------------------------------------------------------------------ L1 / R1 choose the input
press R1
wait 2
expect input silent receiver
expect phase idle
expect status Nothing is coming from the input yet

# Recording from an input that sends nothing gives nothing: the take is too short and thrown away.
press A
wait 1
press A
frames 2
expect phase idle
expect take 0

press R1
frames 40
expect input 12-channel mixer
expect channels 1+2

# ------------------------------------------------------------------ the rows: input, channels, gain
press Down
press Right
press Right
expect channels 5+6
press Left
expect channels 3+4
press Right
press Down
press Right
press Right
expect gain 6
press Left
expect gain 3

# ------------------------------------------------------------------ a take of the mixer
press A
wait 1
expect phase recording
expect take 1.0 0.1
press A
frames 2
expect phase stopped

# While there is a take the settings are locked.
press Right
press R1
frames 2
expect channels 5+6
expect input 12-channel mixer
expect gain 3

press X
frames 4
expect saved rec-001.wav
expect phase idle

# ------------------------------------------------------------------ an input that cannot be opened
press R1
wait 1
expect input broken input
expect status the device refused to start
press A
frames 4
expect phase idle
expect toast No input is ready yet
press Y
frames 4
expect status the device refused to start
press L1
frames 40
expect input 12-channel mixer
expect channels 5+6
expect gain 3

# There is no sample yet, so B has nowhere to lead back to; Select leads to the library.
press B
frames 2
expect screen record
press Select
frames 2
expect screen browser
expect loaded no
