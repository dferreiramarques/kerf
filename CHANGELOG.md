# Changelog

## 0.1.1 (Beta)

Kerf (browser and desktop app):

- Fixed a reverb crash on long slices
- MIDI notes are accepted on all channels
- Projects save and restore all 8 scenes, with stereo audio
- Exporting a sequencer loop keeps the scene's step count, swing, 3-hit flams and stereo pan
- Deleting a slice reindexes scene patterns, mute, solo and multi-tempo
- Keyboard shortcuts no longer fire while typing in text fields
- A first-run product tour, and a mobile layout for the Editor
- The desktop app now includes all of the above (0.1.0 was built in August)

Kerf Lite (VST3): rebuilt by CI, no functional changes.

## 0.1.0 (Beta) - August 2026

First release: the browser app, the Windows desktop app and Kerf Lite.
